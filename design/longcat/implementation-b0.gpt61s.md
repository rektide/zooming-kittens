## Implemented behavior

- **Preferences are not achieved emphasis.** Live scoped identities retain
  neutral weights, optional learned active shares, contextual manual floors and
  a preference generation. Focus changes and owned responses do not advance that
  generation. The goal is derived from those inputs, not the prior emphasized
  pixels.
- **Selected formulas:** `[400,300,200]` → focused A `[630,162,108]`; quiet manual
  `[540,216,144]` teaches A `.6` while retaining neutral `400:300:200`. Blur solves
  `[400,300,200]`; focus return solves `[540,216,144]`. A sibling-only edit teaches
  its visible sibling ratio, not an active share. Neutral guidance rescales all
  neutral weights while preserving their prior total and learned shares.
- **User motion yields.** Relevant content starts/committed extents restart the
  quiet timer. Focus-only events do not. Continuous motion produces no new
  submissions after yielding; focus changes cannot bypass that timer. Quiet
  coherent guidance is accepted from a still-current capture without requiring
  a duplicate event. Ambiguous overlapping motion is labeled unattributed.
- **No learning from partial execution.** Owned target movement and slow client
  commits are explicit adapter assessments. Partial commits do not change the
  goal's content budget. Even after a limited/retired attempt, coherent quiet late
  owned geometry refreshes the expected observation without changing preferences.
  A later sibling-only edit is compared against that refreshed reference.
- **Contextual floors:** an accepted extent below the configured policy minimum
  lowers that member's effective minimum. Presentation/output context changes
  clear the allowance; native bounds are not invented from clamps.
- **Ordinary topology is recoverable.** Full-census live identity, not ordinal
  group placement, owns preference lifetime. Opening, closing, reordering,
  renumbering and cross-group movement reacquire automatically. A known moved
  member carries neutral weight, not its emphasized extent. Same-workspace moves
  preserve learned shares; workspace moves carry weight but reset share/floor.
  Temporarily unsupported groups can disappear from projection while their live
  census identities retain preferences; tab/un-tab resumes after quietness.
- **Finite evidence:** one current attempt, one outstanding command future, one
  completed-attempt mailbox, current group references and cumulative counters.
  Each attempt is capped at `8 * (n-1) + 2` admitted intents and the convergence
  deadline. Replies and position responses are separate. There is no 32/64
  historical admission veto; the 100-focus-switch fixture retains neutral data
  exactly and remains usable.
- **Limited is not permanent.** Stable residuals do not resubmit a failed goal.
  Meaningful focus/context/preference/topology changes permit a new attempt.
  A → B → A clears A's former limitation rather than reviving an old fingerprint
  lock. Results retain desired targets, achieved geometry, blocked boundaries,
  adjacent model estimates and the reason, without teaching the failed goal.
- **Restore/loss:** explicit restore latches neutral intent using current
  preferences and still yields to user motion. Loss stops unsent work and retains
  the outstanding receipt; the same epoch cannot resume. A fresh epoch clears
  hidden preference continuity, waits for quiet acquisition and cannot bypass the
  old pending future or completion evidence. Acquisition from pixels after loss
  is not claimed to recover hidden pre-loss neutral proportions.

## Public call sequence for C/D

The module is [`zk_longcat::feedback`](../../layout/longcat/src/feedback/mod.rs);
`Feedback` is also reexported at the crate root. Its
[DTOs](../../layout/longcat/src/feedback/types.rs) are serializable; the controller
serializes for diagnostics, not resumable native authority.

1. Construct `Feedback::new(FeedbackPolicy)`. Default share/tolerance/quiet/deadline
   are `.7`, two pixels, 500 ms and 1,000 ms. D supplies existing configuration and
   chooses physical-axis `minimum_extent` (`minimum_width` still belongs to D).
2. Project a full `FeedbackInput { source, version, live_members, groups, focus }`.
   The census is **not a delta**: missing identities deliberately retire their
   preferences. Include unsupported live windows in it. Only project a group
   when its axis/content geometry are meaningful; omit unprojectable groups
   instead of inventing an axis/budget. A previously projected group can be
   parked with `unavailable` and automatically resume.
3. Call `observe(input, now_ms)` on relevant captures and `reconsider(now_ms)` on
   timers/evidence completion. Arm `next_reconsideration()` on a real monotonic
   timer. `quiet_deadline_ms(group)` and `awaiting_guidance(group)` expose the
   per-group geometry reacquisition gate; quietness does not itself prove
   coherence or drain a pending command.
4. `Drive(goal)` is one finite current Taffy goal, **not an irrevocable batch**.
   Recompute the next donor-ready edge from latest native/model facts. Before
   sending it, call `begin_command(goal.id, EdgeIntent { basis_version, boundary,
   travel }, now_ms)`. Use the **latest input version**, not the immutable goal's
   creation `basis_version`. Boundary is the member's cross-end edge with an
   actual following member. Travel is signed pixels, not a native fraction.
5. C compiles that intent into A's qualified native request and owns its frozen
   prediction/scale. The application owns/drains the actual future. Record its
   `CommandOutcome` with `record_outcome(key, outcome)`, even after supersession,
   loss or topology changes. `None` outcome means the future remains outstanding;
   the controller cannot finalize or admit another command while it does.
6. Supply `Motion::Owned(key)` only for compatible frozen-prediction progress or
   late client commits. Keys must be known and still in the same source,
   topology/context scope. While an attempt lives its command keys are known;
   afterward the group retains the last command's cumulative prediction identity.
   C should classify delayed convergence against that retained cumulative model,
   not revive an older discarded per-edge prediction. Topology/context/epoch
   retirement does not grant old prediction authority over a new model.
7. Separately `record_response(key, EdgeResponse { observed_version, kind })` for
   adapter-assessed progress or blockage. Install the corresponding **current**
   capture first; an explicit progress response requires a newer version than
   the intent. Blockage can use the same still-current version for a silent
   no-response classification after C's deadline/query. Reply alone does not
   permit another edge. Blocked evidence contains adjacent model estimates,
   not a universal learned client minimum. C decides when other routes are
   exhausted and calls `limit_current` with its reason.
8. On unexplained/ambiguous motion, stop unsent work, ingest observations, drain
   the command, and wait for coherent quietness. `Motion::Unattributed(key)` makes
   the eventual guidance classification explicit. Native clamps that C knows
   are execution-related must remain owned/blocked or limited, not mislabeled
   as a manual edit merely because desired geometry was not achieved.
9. `WaitReason::Completion` means `completed()` contains the one finished record.
   Take/persist it with `take_completed()` before reconsidering. This is bounded
   diagnostic backpressure, not lifetime history. Do not fabricate a receipt to
   empty the mailbox. `preview` clones for hypothetical calculation and changes
   no original preference, intent, receipt, counter or timer obligation.
10. For blur, known outside focus automatically selects neutral preferences.
    For shutdown, call `request_restore` and use the same executor with the
    application's bounded shutdown deadline. For source loss call `lose`, drain
    the future, then acquire a genuinely fresh epoch. `Focus::Unknown` is not blur.

## Geometry/compiler boundary and remaining work

**C remains necessary:** measured gap strips, frozen content budget, model-derived
target extents, physical-axis translation, donor-ready selection, gain/scale,
blocked-edge reachability, position-response deadlines and the one-off windows
refresh. None is replaced by this pure controller. In particular:

- `FeedbackGroup.content_budget` is C's content-only model budget. Hold it through
  owned internal corrections even when transient committed sums disagree.
  `target_extents` are explicitly model-derived; committed sizes stay separate.
- Set `coherent` only when the native geometry model supports it. A quiet mixed-
  time frame is not coherent. Missing target estimates retire an active goal;
  there is no committed-size fallback for further writes.
- Before quiet external-envelope guidance can solve, reacquire the budget/model
  from final coherent geometry after draining owned work. Do not feed the old
  envelope budget into an accepted new user vector, or recalibrate strips from
  mixed-time client commits.
- `FeedbackGroup.context` / `LiveMember.context` describe independent output and
  presentation context. They exclude title/focus/ordinary internal movement and
  positional renumbering. Do not classify a learnable user outer-envelope edit as
  a presentation reset merely to avoid geometry reassessment.
- A's inferred candidate axis can disappear temporarily during mixed-time own
  progress. C still owns validated frozen-model native admission as explained in
  [A's continuation](implementation-a0.gpt61s.md#continue-with-b-then-cd); this
  slice does not weaken native eligibility or change `edge::prepare`.

**D remains necessary:** ordinary stock runner routing, the semantic bridge,
native capability negotiation, configuration, command/observation scheduling,
bounded JSONL diagnostic delivery, source recovery, shutdown composition, the
final feature matrix and native end-to-end acceptance. No running desktop,
installed service, native compositor or upstream repository changed here.
